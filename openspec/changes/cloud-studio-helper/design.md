## Context
기존 서버는 로컬 파일 잠금과 단일 Blender 작업자를 사용한다.

## Goals / Non-Goals
기존 장면의 웹 편집과 발행, 공개 장면의 Blender 다운로드와 수정본 인계를 지원한다. 편집자 컴퓨터의 Apple Silicon macOS 또는 x64 Windows 도우미가 처리한다.

## Decisions
D1에서 개정 비교와 공개 포인터 갱신을 원자적으로 처리한다. 비공개 작업 토큰은 한 작업에만 유효하다. 도우미는 기존 Blender 및 최적화 코드를 실행한다. [배포 결정](../../../docs/adr/0004-클라우드-스튜디오에서-개정별-발행을-편집자-컴퓨터에-위임한다.md)

## Risks / Trade-offs
도우미 중단 시 같은 작업을 재실행할 수 있다. 다른 사람이 저장하면 이전 작업 결과를 거부한다. 원본은 도우미에 다운로드되므로 신뢰하는 편집자에게만 키를 준다.

## 공개 장면 인계 확장
공개 개정의 가구와 조명을 적용한 파일을 베이크와 함께 저장해 다운로드에 작업자가 필요 없게 한다. 수정본을 올리면 편집자 도우미가 원본 식별자와 편집용 모델을 검사한다. 로컬·클라우드 인계는 동일한 3방향 병합을 사용한다. 적용·공개는 각각 개정을 확인한다.

## 도우미 연결
도우미가 기본 브라우저로 스튜디오를 열어 컴퓨터별 연결 키를 전달한다. 스튜디오는 URL에서 키를 지우고, 루프백의 도우미를 확인한 뒤 암호화한 개정별 작업을 보낸다. 두 편집 화면은 같은 연결과 작업 인계를 쓴다. 컴퓨터 로그인 시 자동 시작은 편집자가 선택한다. Windows의 Blender 작업은 네트워크 기능이 없는 AppContainer와 자원 제한이 있는 Job Object에서 실행한다.
