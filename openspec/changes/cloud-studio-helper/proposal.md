## Why
운영자의 맥을 꺼도 다른 편집자가 기존 장면을 편집하고 자신의 컴퓨터에서 발행해야 한다.

## What Changes
공개 사이트의 /studio에서 공동 초안을 저장하고 편집자에게 해당 개정의 베이크를 위임한다. 도우미를 처음 한 번 연 뒤에는 브라우저에서 파일을 끌어놓고 작업 상태와 결과를 확인한다.

## Capabilities
### New Capabilities
- `cloud-studio` — 기존 장면의 클라우드 편집과 로컬 발행 도우미.
### Modified Capabilities

## Impact
Pages Functions, D1, 발행 패널과 Apple Silicon macOS·x64 Windows 도우미를 사용한다.

추가 범위로 공개 장면의 전체 Blender 파일 다운로드와 수정본의 비공개 미리보기·재발행을 지원한다.
