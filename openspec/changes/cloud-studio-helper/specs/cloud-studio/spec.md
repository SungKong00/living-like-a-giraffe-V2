## ADDED Requirements

### Requirement: 독립적인 편집과 발행
시스템은 운영자 맥이 오프라인이어도 권한 있는 편집자가 기존 장면을 저장하고 자기 컴퓨터에서 구운 개정을 발행할 수 있어야 한다(SHALL).

#### Scenario: 다른 컴퓨터에서 발행
- **WHEN** 편집자가 초안을 저장하고 도우미로 구운 결과를 확인한 뒤 공개한다
- **THEN** 방문자는 새 개정과 일치하는 모델을 본다

#### Scenario: 경합과 접근 제한
- **WHEN** 저장 이후 이전 개정의 결과가 도착하거나 권한 없는 사용자가 원본을 요청한다
- **THEN** 요청을 거부하고 현재 공개본을 유지한다

### Requirement: 공개 장면 Blender 왕복
시스템은 인증된 편집자가 공개 개정의 배치·재질 옵션·조명을 반영한 전체 .blend를 내려받고, 수정본을 비공개로 검토한 뒤 발행하도록 해야 한다(SHALL).

#### Scenario: 원본으로 이어서 작업
- **WHEN** 편집자가 공개본을 내려받거나 직전 공개본을 복원한 뒤 내려받는다
- **THEN** 해당 개정에서 만든 Blender 파일을 운영자 컴퓨터 없이 받는다

#### Scenario: 수정본을 검토하고 적용
- **WHEN** 편집자가 공개본에서 수정한 파일을 올리고 도우미로 처리한다
- **THEN** 웹 초안과 달라진 항목을 병합하고 미리본 후 초안에 반영할 수 있으며 발행 전까지 방문자 화면은 유지된다

### Requirement: 스튜디오에서 도우미 사용
시스템은 macOS와 Windows 편집자가 도우미를 한 번 연결한 뒤 웹에서 업로드와 베이크를 요청하고 진행 상태를 확인할 수 있게 해야 한다(SHALL).

#### Scenario: 파일을 끌어놓고 미리보기
- **WHEN** 편집자가 연결한 브라우저에서 .blend를 끌어놓는다
- **THEN** 전송률을 표시하고 이 컴퓨터에 검사 작업을 전달하며 결과를 비공개로 검토할 수 있다

#### Scenario: 다음 로그인
- **WHEN** 편집자가 자동 시작을 선택한 뒤 같은 컴퓨터에 로그인해 스튜디오를 연다
- **THEN** 해당 브라우저가 도우미와 다시 연결되며, 도우미가 꺼져 있으면 스튜디오에서 열 수 있다

#### Scenario: 처음 접속한 브라우저
- **WHEN** 이 브라우저에 도우미 연결 기록이 없다
- **THEN** 현재 운영체제용 다운로드와 설치한 도우미 열기를 함께 표시하고 다른 운영체제용 다운로드만 접는다

#### Scenario: 도우미 연결 완료
- **WHEN** Blender 파일 또는 발행 패널에서 이 컴퓨터의 도우미 연결이 확인된다
- **THEN** 연결과 다운로드 조작은 접어서 표시하고 다시 펼칠 수 있다. 연결 상태와 작업 진행률은 계속 표시하며 연결이 끊기면 설치와 실행 조작을 다시 표시한다.

#### Scenario: 조명 굽기 진행률
- **WHEN** 도우미가 업로드한 파일의 검토용 조명이나 발행 미리보기의 조명을 굽는다
- **THEN** 작업을 처리하는 컴퓨터의 스튜디오에 완료된 베이크 비율을 표시하고 굽기 이후 단계는 해당 작업 이름을 표시한다
