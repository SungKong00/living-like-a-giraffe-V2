# Spec Delta

## Purpose

편집자가 날짜별 작업 시작점, Blender 교체 전 장면과 직접 이름 붙인 버전을 나중에 찾아 미리 본 뒤 현재 월드의 비공개 초안으로 복구할 수 있게 한다.

## ADDED Requirements

### Requirement: 편집 전 버전 보관
관리자 스튜디오는 하루의 첫 초안 변경, Blender 적용 및 버전 복원 직전의 배치와 모델을 지속적으로 보관해야 한다(MUST).

#### Scenario: 하루의 첫 저장
- **WHEN** 같은 서울 날짜에 두 창에서 여러 차례 초안을 저장한다
- **THEN** 첫 번째로 성공한 변경 직전 버전을 하루에 한 번 보관한다

#### Scenario: Blender 파일 적용
- **WHEN** 충돌을 해결하고 Blender 수정본을 초안에 적용한다
- **THEN** 적용 직전 원본과 배치를 보관하고 이후에도 그 모델로 미리보기와 복원을 제공한다

### Requirement: 이름 붙이기와 복원
관리자는 저장된 초안에 이름을 붙이고 목록에서 버전을 읽기 전용으로 미리 본 뒤 새 초안으로 복원할 수 있어야 한다(MUST).

#### Scenario: 확인 후 복원
- **WHEN** 관리자가 과거 버전을 미리 보고 복원한다
- **THEN** 해당 모델과 배치로 새 초안을 만들고 직전 초안을 보관한다. 방문자에게는 기존 공개본이 보인다

#### Scenario: 다른 창에서 편집
- **WHEN** 버전을 고른 뒤 다른 편집자가 초안을 저장한다
- **THEN** 이전 개정에 대한 복원 요청을 거부하고 최신 초안을 보존한다
