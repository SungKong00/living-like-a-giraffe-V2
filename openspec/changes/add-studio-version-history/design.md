# Design

## Context

편집 세션의 Undo와 공개본 교체는 기존 월드 개정 설계를 따른다. [원본 보존 결정](../../../docs/adr/0005-편집-버전이-참조하는-원본과-배치를-함께-보존한다.md)에 따라 로컬 서버와 Pages API는 같은 편집기를 제공한다.

## Goals / Non-Goals

초안의 배치와 해당 Blender 모델을 함께 복구한다. 발행 이력, 공유 자료실 자체의 변경 이력과 오프라인 편집은 기존 범위에 둔다.

## Decisions

- 서울 날짜의 첫 초안 변경에 하루 시작점을 만든다. 단순 접속과 취소된 인계는 기록을 만들지 않는다.
- 현재 개정을 확인하고 변경 직전 상태를 새 초안과 함께 커밋한다. 로컬은 개정별 파일과 기존 원자적 상태 파일을 사용하고 클라우드는 D1 트랜잭션으로 버전을 추가한다. 기록이 참조하는 원본·카탈로그·편집 모델은 보존한다.
- 상단 기록 버튼에서 최신순 목록을 열고 이름을 붙여 저장한다. 항목을 고르면 읽기 전용 장면을 표시한다. 복원 후에는 새 초안을 다시 열고 이전 초안도 기록에서 찾을 수 있다.

## Risks / Trade-offs

이력을 보관하면 저장 공간이 늘어난다. 큰 모델은 개정 간 공유하고 버전 목록은 제목과 시각만 읽는다.
