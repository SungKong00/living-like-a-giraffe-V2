# Spec Delta

## ADDED Requirements

### Requirement: 관람 장면의 캐릭터

관람 화면은 공개본의 캐릭터를 공개 당시의 모델·위치·방향·크기·체형·착용물·동작으로 보여야 한다(MUST). 방은 구운 빛을 유지하고 캐릭터는 관람 장면의 실시간 빛을 받으며, 발밑에 둥근 그림자가 보여야 한다(MUST). 모델을 열 수 없는 캐릭터는 보이지 않는다.

#### Scenario: 공개한 캐릭터 보기

- **WHEN** 운영자가 사우나에 케이프를 입히고 걷기 동작을 정한 캐릭터를 둔 초안을 공개한다
- **THEN** 관람 화면의 사우나에 같은 자리와 방향으로 케이프를 입은 캐릭터가 걷기 동작을 하고 발밑에 그림자가 보인다

### Requirement: 공개본별 캐릭터 파일 고정

공개본은 그 레이아웃이 쓰는 모델·동작 파일을 고정해야 한다(MUST). 자료실에서 모델에 새 버전을 올리거나 기본 키를 바꿔도 다시 공개하기 전에는 관람 화면이 바뀌지 않아야 한다(MUST). 공개 파일 경로는 현재와 이전 공개본이 쓰는 파일만 내준다(MUST).

#### Scenario: 공개 뒤 모델 교체

- **WHEN** 공개본을 한 번 연 뒤 그 공개본이 쓰는 모델에 새 버전을 올린다
- **THEN** 관람 화면은 이전 파일을 계속 보여주고, 초안을 다시 공개하면 새 파일을 보여준다

#### Scenario: 공개하지 않은 파일

- **WHEN** 관람객이 공개본이 쓰지 않는 자료실 파일 ID로 공개 파일 경로를 요청한다
- **THEN** 서버가 404로 응답한다

### Requirement: 캐릭터의 행사 페이지 연결

운영자는 캐릭터 편집기에서 누르면 열 행사 페이지를 고르거나 연결을 풀 수 있어야 한다(MUST). 관람객이 연결 페이지가 있는 캐릭터를 누르면 그 페이지가 열려야 한다(MUST). 페이지를 지우면 그 페이지를 가리키던 캐릭터의 연결이 풀린다(MUST).

#### Scenario: 캐릭터를 눌러 페이지 열기

- **WHEN** 운영자가 캐릭터에 행사 페이지를 연결해 공개하고, 관람객이 그 캐릭터가 있는 방에서 캐릭터를 누른다
- **THEN** 연결한 행사 페이지가 열린다
