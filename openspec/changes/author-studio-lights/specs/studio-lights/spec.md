# Spec Delta

## Purpose

제작자가 전시 공간과 작품에 맞는 빛을 선택하고 장면에서 위치와 조준점을 잡아, 같은 조명을 스튜디오·비공개 검토·전체 Blender 파일에서 이어서 사용하게 한다.

## ADDED Requirements

### Requirement: 용도별 조명 선택과 배치
편집기는 점광원, 스포트라이트, 직사각 면광원을 만들고 켜짐·색·출력·위치를 조절할 수 있어야 한다(MUST). 스포트라이트는 빔 각도·경계, 면광원은 폭·높이를 제공한다. 방향성이 있는 빛은 장면에서 비출 지점을 정한다.

#### Scenario: 작품을 강조하기
- **WHEN** 운영자가 작품이 있는 방에 스포트라이트를 추가하고 비출 곳을 누른다
- **THEN** 빛이 그 지점을 향하고 빔 각도와 경계를 변경할 수 있다. 끄고 다시 켜면 조명 설정이 복원된다.

#### Scenario: 편집 중 검토
- **WHEN** 위치 지정을 취소하거나 조명 설정을 변경하고 배치 미리보기를 연다
- **THEN** 취소 시 위치가 유지되고 미리보기는 같은 설정을 사용한다. 조명 표시는 편집기에만 나타나며 공개본은 유지된다.

### Requirement: 조명 호환성과 전체 파일 인계
세 종류의 설정은 웹 초안과 Blender 파일 사이에서 고유 ID로 복원되어야 한다(MUST). 기존 점광원을 열 수 있어야 하며, 굽기는 실제 조명 설정이 같은 경우 재사용할 수 있어야 한다(MUST).

#### Scenario: 제작본 왕복
- **WHEN** 제작자가 서로 다른 조명이 있는 전체 파일을 받아 광량 또는 빛의 모양을 수정하고 다시 올린다
- **THEN** 스튜디오는 해당 변경을 인식하여 웹 편집과 병합하거나 충돌 선택을 제시한다.

### Requirement: Blender 원본 광원 편집
스튜디오는 원본의 점·스포트·면광원을 안정적인 ID로 선택하고 밝기, 색, 위치, 방향성 광원의 조준점을 바꿀 수 있어야 한다(MUST).

#### Scenario: 구워진 사우나 조명 끄기
- **WHEN** 제작자가 원본 조명을 끄거나 이동한다
- **THEN** 편집 장면에서 이전에 구운 조명과 새 직접광이 겹치지 않고 공개본은 유지된다. 원본값 복원 시 모델의 조명을 다시 사용한다.

#### Scenario: 전체 월드 조명 인계
- **WHEN** 원본 전체 조명의 값을 바꾸고 전체 파일을 내려받는다
- **THEN** 같은 Blender 오브젝트와 발광면 모양이 유지되고 변경된 값이 반영된다.
