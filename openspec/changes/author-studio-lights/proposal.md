# Proposal

## Why

제작자가 공간 전체를 밝힐 때와 작품 하나를 강조할 때 필요한 빛이 다르다. 현재 스튜디오는 점광원만 만들고 좌표만으로 조명을 옮긴다.

## What Changes

- 방에서 점광원·스포트라이트·직사각 면광원을 용도별로 추가하고 장면에서 위치와 비출 곳을 지정한다.
- 조명별 색·출력·켜짐과 종류별 빛 모양을 실시간으로 조절하고 전체 Blender 파일로 왕복한다.

- Blender 원본의 기본 광원을 선택해 위치·출력·색·방향을 바꾸고 원본값을 복원한다. 기존에 구운 빛은 재조명할 때 제외한다.

## Capabilities

### New Capabilities

- `studio-lights` — 제작자가 방별 조명을 배치·검토·인계하는 규칙.

### Modified Capabilities

## Impact

스튜디오의 장면 목록과 속성 패널, Babylon 광원, 초안 검증·병합, 굽기 캐시, Blender 작업자가 영향을 받는다. 기존 점광원 초안을 계속 열 수 있어야 한다.
