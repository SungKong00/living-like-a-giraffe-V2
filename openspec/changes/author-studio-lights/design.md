# Design

## Context

방 배경과 간접광은 모델별로 준비하고, 편집용 가구와 추가한 광원은 Babylon에서 렌더한다. 최종 조명 검토와 공개는 기존 발행 절차를 따른다.

## Goals / Non-Goals

스튜디오에서 관리하는 광원의 위치, 방향, 모양을 방 로컬 좌표로 교환한다. 원본 광원의 형태와 소속은 Blender에서 관리하고, 편집 가능한 속성은 안정적인 ID를 기준으로 변경값만 초안에 저장한다.

## Decisions

- 공통 속성은 이름·방·위치·색·출력·켜짐이다. 종류별 모양은 하나의 값으로 검증·병합하여 종류 변경과 이전 종류의 속성이 섞이지 않게 한다. 기존 모양 없는 조명은 점광원으로 읽는다.
- 스포트와 면광원의 방향은 로컬 -Z와 단위 쿼터니언으로 표현하여 제작자가 Blender에서 돌린 면의 장축도 보존한다. UI에서 위치와 조준점은 3D 표면을 눌러 지정한다.
- 편집용 표식은 방문자 파일과 배치 미리보기에 넣지 않는다. 꺼진 광원은 초안과 전체 파일에 남고 굽기 입력에서 제외한다.

- 원본을 수정하지 않은 초안은 기존 고정 조명 이미지를 사용한다. 원본 빛이 바뀌면 같은 메시의 고유 색과 원본 광원을 제외한 환경광에 현재 직접광을 더한다. 전체 파일과 최종 굽기는 원본 오브젝트에 변경된 속성만 적용한다.

## Risks / Trade-offs

방별 직접광 미리보기와 Cycles의 간접광·그림자는 차이가 난다. 최종 노출과 다른 방으로 번지는 빛은 비공개 결과에서 검토한다.

장면 조작은 선택한 광원에만 임시 변환 노드를 연결한다. 스튜디오가 월드 좌표의 포인터 변환을 광원의 저장 좌표계로 바꿔 기존 조명 편집 경로에 전달한다. 한 드래그는 미리보기와 마지막 한 번의 초안 변경으로 처리한다.
