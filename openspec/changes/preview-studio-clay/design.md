# Design

## Context

v06의 서쪽 나무 벤치 두 단은 원본 팩에서 추출한다. 기린은 독립된 편집용 Blender 원본과 스킨·착용 기준점을 담은 GLB를 사용한다.

## Goals / Non-Goals

시점·축척을 동기화해 실제 메시 변형을 비교한다. 배회 애니메이션과 발행은 기존 월드 기능에 둔다.

## Decisions

관리자 경로에서 두 대상만 제공하고 스튜디오가 비교창을 열 때 읽는다. 한 Babylon 장면에서 같은 카메라 설정으로 양쪽을 그린다. 원본 좌표에서 Node Geometry로 새 위치를 계산해 재선택할 때 변형이 누적되지 않게 한다. 모델 공통 좌표에서 연속적으로 변형해 기린의 채색·몸통·의상이 함께 움직인다. 양쪽 기린은 각각 독립된 골격으로 같은 포즈를 재생하고 오른쪽에서만 체형 비율을 바꾼다. 각 기린의 피부와 의상은 그 기린의 골격을 공유하고 점토 조형은 스키닝 전 좌표에서 변형한다. 단단한 장식은 뼈 아래의 명명한 기준점을 부모로 삼는다. 가늘어진 몸통과 길어진 목·다리에 골격과 케이프를 맞춘다. 시안과 월드 편집기는 서 있는 기린의 기준 높이로 목 위쪽부터 변형을 줄여 눈·코·입의 모양을 보존한다.

## Risks / Trade-offs

벤치의 긴 면에 중간 정점이 적어 해당 면을 세분화한다. 깊이와 크기는 모델에 맞춘 범위로 제한한다.
