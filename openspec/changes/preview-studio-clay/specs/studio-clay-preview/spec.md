# Spec Delta

## Purpose

운영자가 스튜디오에서 실제 사우나 벤치와 점토 기린을 골라 원본과 점토 조형을 같은 시점에서 비교하고 강도와 표면의 굴곡을 직접 조정한다.

## ADDED Requirements

### Requirement: 대상별 원본과 점토 조형 비교
스튜디오는 원본과 시안을 같은 시점과 조명으로 보여주고 방금 선택한 대상의 원본·약하게·보통·강하게 단계를 즉시 반영해야 한다(MUST).

#### Scenario: 기린 비교
- **WHEN** 운영자가 기린을 선택하고 보통에서 강하게로 바꾼다
- **THEN** 같은 자세의 기린에서 굴곡이 깊어지고 원본 보기와 카메라 위치가 유지된다

### Requirement: 세부 조정과 시안 격리
운영자는 대상별 굴곡 강도와 눌림 깊이, 자국 크기를 조정할 수 있어야 한다(MUST). 비교 중 대상 전환은 각각의 조정을 보존하고 시안은 월드 초안이나 공개본을 바꾸지 않아야 한다(MUST).

#### Scenario: 대상 전환
- **WHEN** 벤치의 눌림 깊이를 조정한 뒤 기린을 보고 벤치로 돌아온다
- **THEN** 벤치에 조정한 값이 표시되고 원본 단계를 선택하면 양쪽 외형이 일치한다

### Requirement: 착용 가능한 기린의 포즈 비교
스튜디오는 새로 제작한 기린의 피부·옷이 골격에 맞춰 변형되고 장식이 부착 위치를 따라가는 모습을 원본과 점토 강도별로 보여줘야 한다(MUST). 제작자는 편집 원본에서 같은 골격과 기준점을 재사용할 수 있어야 한다(MUST).

#### Scenario: 옷과 장식을 착용하고 고개를 기울임
- **WHEN** 기린에 케이프와 귀 장식을 착용하고 포즈를 바꾼다
- **THEN** 양쪽 기린이 같은 포즈를 취하고 케이프는 어깨를, 귀 장식은 귀를 따라간다
