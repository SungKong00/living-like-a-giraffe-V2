# Proposal

## Why

운영자가 기존 벤치와 기린의 실루엣에 점토처럼 눌리고 굽은 형태가 어울리는지 실제 모델로 판단하려 한다.

## What Changes

PC 스튜디오에 같은 시점에서 원본과 변형을 비교하는 시안을 추가한다. 강도 네 단계와 눌림 깊이, 굴곡 크기를 바꿀 수 있다. 기린은 별도 제작한 점토 캐릭터로 골격 포즈·의상·액세서리 추종도 비교한다.

## Capabilities

### New Capabilities

- `studio-clay-preview`는 대상별 점토 조형 비교를 제공한다.

### Modified Capabilities

## Impact

스튜디오 전용 화면과 인증된 시안 모델 조회 경로를 추가한다. 시안 설정은 발행 데이터에 쓰지 않는다.
