# Tasks

## 1. 제작자 인계와 자산 빌드

- [ ] 1.1 방 기준점과 가구 표시 속성을 정하고 월드 자산 안내에 인계 예시를 추가한다. 별도 제작자가 안내만으로 한 파일에 의자와 고정 벽을 구분할 수 있는지 확인한다.
- [ ] 1.2 지정 장면의 모델·기준점 목록을 같은 버전으로 생성하고 빈 ID, 중복 ID, 소속 방 누락 표본이 문제 오브젝트를 가리키는지 확인한다.
- [ ] 1.3 고정 구조와 편집 루트별 최적화를 적용한다. 같은 재질의 의자와 바닥에서 의자 전체만 이동하고 원래 자리가 비는지 확인한다.

## 2. 웹 편집과 발행

- [ ] 2.1 같은 Babylon.js 장면으로 관리자 조작과 방문자 미리보기를 구성하고 회전한 방에서 가구를 이동·회전·확대한 뒤 저장·재접속 결과를 비교한다.
- [ ] 2.2 방·가구에 붙는 클릭 범위와 콘텐츠 편집을 연결한다. 새 페이지 추가, 기존 행사 개요, 외부 링크, 상세 URL 직접 진입을 확인한다.
- [ ] 2.3 모델 교체 검증, 권한 확인, 초안과 공개 버전 전환을 연결한다. 누락 참조가 있는 발행과 방문자의 저장 요청이 차단되고 직전 공개본이 열리는지 확인한다.
- [ ] 2.4 공개 화면에서 편집 도구 로드를 분리하고 실제 모바일에서 기존 최적화본과 첫 조작 시간·프레임 시간·드로우콜·다운로드 용량을 같은 조건으로 비교한다.

## 3. 전체 파일 인계와 동시 편집

- [ ] 3.1 단일 원본 업로드의 권한·장면·필수 외부 자원을 검증하고 누락 자원이 있는 후보에는 경로를 표시한다. 원본 접근 권한과 직전 발행 상태를 확인한다.
- [ ] 3.2 서버 Blender 작업에서 인계 기준과 개정을 고정하고 전체 사본에 최종 배치를 반영한다. 별도 환경에서 다시 열어 다른 장면·재질·ID·변환이 보존되는지 확인한다.
- [ ] 3.3 생성 상태·캐시·재시도를 연결한다. 중복 요청이나 생성 중 편집에서도 결과 파일이 요청 개정과 일치하며 실패 시 이전 파일이 최신으로 표시되지 않는지 확인한다.
- [ ] 3.4 재업로드 세 상태 비교와 가구별 충돌 해결을 구현한다. 의자 단독 변경·양쪽 이동·삭제·기준 불명·검토 중 동시 발행을 시험하고 병합 결과를 다시 다운로드해 확인한다.
- [ ] 3.5 제작자 인계 절차를 월드 자산 안내에 반영하고, 일반 Blender만 설치된 PC에서 다운로드→외형 수정→전체 파일 업로드가 되는지 확인한다.

## 4. 카메라·조명·모바일 품질

- [ ] 4.1 시험할 시야 범위와 기기를 정하고 전체·방 집중·전환, 세로·가로, 터치 관성에서 회전·줌 한계와 가구 클릭 가능 여부를 확인한다.
- [ ] 4.2 웹 편집기에 실시간 고정 광원을 연결하고 서버에서 발행 배치의 라이트맵을 생성한다. 사우나 의자를 이동한 뒤 편집과 모바일 공개본에서 새 그림자·중복 조명·UV·클릭 위치를 비교한다.
- [ ] 4.3 고정 구조와 반복 가구에 경량화를 적용한 뒤 허용 각도 양끝과 최대 확대에서 누락 면·반사·그림자·클릭 범위를 점검한다. 내려받은 원본의 제작 구조와 웹 결과를 각각 확인한다.
- [ ] 4.4 대표 기기·네트워크의 첫 조작 시간과 프레임 시간 95백분위를 기준으로 제안한 품질 옵션을 비교하고 발행용 카메라·조명·성능 예산을 확정한다.
- [ ] 4.5 스냅샷 기반 비동기 발행과 상태 표시를 연결한다. 작업 중 새 초안, 역순 완료, 실패·재시도, 링크만 수정한 개정을 검증해 이전 공개본 보존과 렌더 자산 재사용을 확인한다.

## 5. 가구 복제와 기기별 이용

- [ ] 5.1 PC에서 모델별 옵션 정의·허용값과 개별 가구 ID를 사용해 복제·옵션 편집을 구현한다. 색과 두 번째 옵션을 바꾼 뒤 새로 열어 원본과 복제본의 상태를 비교한다.
- [ ] 5.2 발행 시 옵션 정규화·공용 자원·호환 인스턴싱을 적용한다. 같은 옵션과 다른 옵션이 섞인 표본에서 자원 수와 드로우콜을 비교하고 서로 다른 베이크·클릭 대상이 보존되는지 확인한다.
- [ ] 5.3 저장된 최신 초안과 발행본을 각각 전체 파일로 내려받아 복제본의 고유 ID와 실제 Blender 외형을 확인한다. 양쪽에서 독립·충돌 옵션을 수정해 재인계와 재시도를 검증한다.
- [ ] 5.4 휴대폰에서는 편집 UI와 편집 번들 없이 방 탭·개요·상세·외부 링크·별도 목록을 제공한다. 아이폰과 안드로이드에서 이동 기린 자산과 배회 로직이 실행되지 않는지 확인한다.
- [ ] 5.5 직전 공개본을 복원해 모델·라이트맵·페이지와 각 가구의 클릭 연결이 같은 개정이며 작업 중 인계의 비교 기준도 남아 있는지 확인한다.
