# Spec Delta

## Purpose

제작자와 운영자가 사이트를 통해 전체 월드 파일 한 개를 주고받고, 웹 배치와 제작 변경이 다음 인계 이후에도 유지되도록 한다.

## ADDED Requirements

### Requirement: 편집 가능한 전체 파일 다운로드
사이트는 권한 있는 사용자에게 요청한 개정의 가구 배치가 반영된 자족적인 전체 .blend 파일을 제공해야 한다(MUST).

#### Scenario: 제작자가 일반 Blender에서 파일 열기
- **WHEN** 제작자가 창가로 옮긴 의자가 있는 개정을 다운로드해 별도 컴퓨터에서 연다
- **THEN** 파일 하나로 해당 의자의 최종 위치와 방향, 제작용 계층·재질·조명·다른 장면을 확인하고 편집할 수 있다

#### Scenario: 반복 요청과 생성 실패
- **WHEN** 같은 개정을 반복 요청하거나 새 개정 생성 중 오류가 발생한다
- **THEN** 같은 개정의 배치를 중복 적용하지 않으며 실패한 요청에는 오류 상태를 표시하고 완성 전 파일 또는 다른 개정의 파일을 전달하지 않는다

### Requirement: 재업로드 시 양쪽 변경 보존
서버는 인계 기준과 제작 후보·현재 웹 배치를 비교하고, 독립적인 변경을 보존하며 동일 대상의 충돌은 해결 후 발행해야 한다(MUST).

#### Scenario: 다른 대상을 각각 수정
- **WHEN** 다운로드 이후 제작자는 벽 색을 바꾸고 운영자는 의자를 옮긴다
- **THEN** 전체 파일을 재업로드하고 발행하면 새 벽 색과 새 의자 위치가 웹과 다음 전체 다운로드에 함께 반영되고 의자의 행사 연결도 유지된다

#### Scenario: 제작자만 이전에 웹에서 옮긴 의자를 다시 이동
- **WHEN** 다운로드 당시 창가에 있던 의자를 제작자가 옮기고 웹 위치는 그대로다
- **THEN** 재업로드 후보에 제작자의 새 위치가 표시된다

#### Scenario: 같은 가구의 서로 다른 변경
- **WHEN** 양쪽에서 같은 의자를 다른 자리로 옮기거나 한쪽에서 수정 중인 의자를 다른 쪽에서 삭제한다
- **THEN** 해당 ID와 변경을 표시하고 담당자가 선택하거나 참조를 정리할 때까지 이전 공개본이 유지된다

#### Scenario: 기준 불명과 동시 발행
- **WHEN** 재인계 파일의 출발점을 식별할 수 없거나 검토 도중 새 개정이 발행된다
- **THEN** 자동 덮어쓰기를 중단하고 기준 확인 또는 최신 상태와의 재비교를 거친다

### Requirement: 최신 저장 초안과 복제본의 왕복
편집 화면의 기본 전체 다운로드는 마지막 저장 초안의 가구별 ID·배치·옵션을 포함하고 공개본 다운로드를 별도로 제공해야 한다(MUST).

#### Scenario: 베이크 대기 중 초안을 받아 재인계
- **WHEN** 관리자가 다른 색의 의자를 복제해 초안을 저장하고 전체 다운로드를 요청한다
- **THEN** 공개본 베이크 완료 전에 해당 초안의 전체 파일을 만들 수 있다. Blender에서 두 의자를 각각 편집할 수 있고 재업로드 후에도 중복 생성 없이 가구별 옵션과 웹 클릭 연결이 유지된다.
