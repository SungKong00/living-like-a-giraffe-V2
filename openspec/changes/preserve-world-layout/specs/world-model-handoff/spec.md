# Spec Delta

## Purpose

제작자가 한 파일 안에서 편집할 가구를 지정해 전달하면, 웹용 월드를 최적화한 뒤에도 운영자가 같은 가구를 식별하고 가구 전체를 독립적으로 배치할 수 있게 한다.

## ADDED Requirements

### Requirement: 가구 단위 인계
인계 도구는 지정된 장면에서 방 기준점과 이동 가능한 가구의 고유 ID, 소속 방, 기본 변환을 식별해야 한다(MUST).

#### Scenario: 여러 부품으로 만든 의자
- **WHEN** 제작자가 한 방의 좌판·다리를 동일한 편집 루트 아래 묶고 루트에 가구 ID를 부여한다
- **THEN** 웹에서는 의자 한 개를 선택해 모든 부품을 함께 옮길 수 있고 같은 방의 벽·바닥은 제자리에 있다

#### Scenario: 식별자 오류
- **WHEN** 편집 대상으로 표시한 가구의 ID가 비었거나 중복되거나 소속 방을 찾을 수 없다
- **THEN** 도구는 해당 오브젝트와 원인을 알려주고 이 모델 버전을 발행할 수 없게 한다

### Requirement: 최적화 후 편집 경계 보존
웹용 자산은 최적화 이후에도 가구 ID와 편집 루트의 대응을 하나씩 보존해야 한다(MUST).

#### Scenario: 의자와 바닥이 같은 재질을 사용
- **WHEN** 최적화한 월드에서 의자를 원래 자리에서 옮긴다
- **THEN** 의자 전체가 한 번만 표시되고 원래 자리에 의자 조각이 남거나 바닥이 따라오지 않는다

### Requirement: 단일 원본 인계와 웹 파생본
제작자는 전체 .blend 한 개를 전달하며 시스템은 지정 장면과 필수 자원을 검증한 후 웹용 파생본을 생성해야 한다(MUST).

#### Scenario: 외부 파일 누락
- **WHEN** 제작자의 로컬 경로에서만 열리는 필수 텍스처나 라이브러리가 있다
- **THEN** 해당 경로와 조치할 항목을 표시하고 후보를 발행하지 않는다

#### Scenario: 웹 전용 경량화
- **WHEN** 고정 구조의 메시를 합치거나 관람용 모델에서 일부 면을 생략한다
- **THEN** 전체 다운로드 파일에는 제작자가 넘긴 편집 구조와 원래 면이 보존된다

### Requirement: 동일 옵션의 렌더 자원 재사용
발행 빌드는 같은 모델에서 결과가 같은 형상·재질 옵션을 식별해 공유 가능한 자원을 재사용하고 개별 가구 ID와 위치별 베이크 결과를 보존해야 한다(MUST).

#### Scenario: 동일 옵션과 다른 색이 공존
- **WHEN** 같은 모델·옵션의 의자 두 개와 색만 다른 의자 하나를 서로 다른 조명 위치에 놓고 발행한다
- **THEN** 같은 두 의자의 호환되는 형상·재질 자원은 중복 생성되지 않고 세 의자 모두 자기 색·그림자·클릭 대상을 유지한다.
