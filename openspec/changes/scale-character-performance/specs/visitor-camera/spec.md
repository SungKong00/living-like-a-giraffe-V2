# Spec Delta

## Purpose

관람 화면의 카메라가 월드를 어느 방향에서 비추고, 방문자가 화면을 어떻게 옮기고 확대하는지를 정한다.

## ADDED Requirements

### Requirement: 고정 방향 관람

관람 화면의 카메라는 정해진 한 방향에서 월드를 비추어야 한다(MUST). 방문자의 어떤 조작이나 방 전환으로도 보는 방향이 바뀌지 않아야 한다(MUST). 배치 미리보기도 같은 방향으로 보여야 한다(MUST). 스튜디오의 편집 장면은 이 제한을 받지 않는다.

#### Scenario: 끌어도 방향 유지

- **WHEN** 방문자가 관람 화면을 좌우·상하로 끌거나 두 손가락으로 돌리는 동작을 한다
- **THEN** 월드의 벽과 바닥이 화면에서 같은 각도로 보이고 반대편 면이 드러나지 않는다

#### Scenario: 방 전환

- **WHEN** 방문자가 전체 보기에서 방을 고른 뒤 다시 전체 보기로 돌아온다
- **THEN** 두 화면 모두 처음과 같은 방향에서 월드를 비춘다

### Requirement: 화면 이동

방문자는 관람 화면을 끌어서 보는 자리를 옮길 수 있어야 한다(MUST). 끄는 동안 포인터 아래의 바닥이 포인터를 따라와야 한다(MUST). 누른 자리에서 6픽셀보다 적게 움직이고 뗀 조작은 이동이 아니라 누르기로 다룬다(MUST).

#### Scenario: 한 손가락으로 이동

- **WHEN** 방문자가 휴대폰에서 한 손가락으로 화면을 왼쪽으로 끈다
- **THEN** 월드가 손가락을 따라 왼쪽으로 움직이고 오른쪽에 있던 방이 화면에 들어온다

#### Scenario: 누르기와 구분

- **WHEN** 방문자가 캐릭터나 방을 누르고 거의 움직이지 않은 채 뗀다
- **THEN** 화면은 이동하지 않고 그 캐릭터의 페이지나 방이 열린다

### Requirement: 이동 범위

화면 이동은 월드가 화면 밖으로 완전히 나가지 않는 범위로 제한해야 한다(MUST). 확대·축소한 뒤에도 같은 제한을 지켜야 한다(MUST).

#### Scenario: 끝까지 끌기

- **WHEN** 방문자가 한 방향으로 계속 끈다
- **THEN** 월드의 가장자리가 화면 가운데에 닿으면 더 움직이지 않고 빈 바탕만 보이는 화면이 되지 않는다
