# Spec Delta

## ADDED Requirements

### Requirement: 기린 자료실

운영자는 리깅된 기린 모델 하나와 동작 파일 여러 개를 GLB로 올리고 지울 수 있어야 한다(MUST). 서버는 스킨이 없는 모델, 애니메이션이 없는 동작, 모델 관절과 하나도 맞지 않는 동작을 이유와 함께 거부한다(MUST).

#### Scenario: 맞지 않는 동작 파일

- **WHEN** 다른 뼈대로 만든 동작 파일을 올린다
- **THEN** 업로드가 거부되고 기린 모델의 관절 이름과 맞지 않는다는 안내가 보인다

### Requirement: 기린 배치와 동작 설정

운영자는 추가 메뉴에서 기린을 방에 놓고, 기린 편집기에서 이름·방·위치·방향·크기·동작·속도를 바꿀 수 있어야 한다(MUST). 월드 패널의 기본 동작과 속도를 따르지 않는 값은 덮어쓰기로 표시하고 되돌릴 수 있어야 한다(MUST). 편집 장면은 선택한 동작을 반복 재생하고 기린을 눌러 선택할 수 있어야 한다(MUST).

#### Scenario: 기린 하나만 다른 동작

- **WHEN** 월드 기본 동작이 걷기일 때 기린 하나의 동작을 풀 뜯기로 바꾼다
- **THEN** 그 기린만 풀 뜯기를 재생하고 동작 항목에 덮어쓰기 표시가 보이며, 되돌리면 다시 걷기를 재생한다
