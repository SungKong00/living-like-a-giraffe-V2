# Spec Delta

## ADDED Requirements

### Requirement: 월드 기본 점토 설정

월드 패널은 점토 강도·눌림 깊이·자국 크기를 원본·약하게·보통·강하게 단계와 세부 값으로 바꿀 수 있어야 한다(MUST). 덮어쓰지 않은 모든 가구와 기린은 이 값을 따른다. 편집 장면은 값을 바꾸는 동안 바로 반영한다(MUST).

#### Scenario: 월드 단계 변경

- **WHEN** 운영자가 월드 점토를 보통에서 강하게로 바꾼다
- **THEN** 덮어쓰지 않은 가구가 모두 강하게 바뀌고 초안의 `defaults.clay`에 저장된다

### Requirement: 개체별 점토 덮어쓰기

가구와 기린 편집기는 그 개체의 점토 값을 월드 값과 다르게 정할 수 있어야 하고, 덮어쓴 항목을 표시하며 월드 값으로 되돌릴 수 있어야 한다(MUST). 개체를 삭제하거나 Blender 인계로 사라지면 그 덮어쓰기도 남지 않아야 한다(MUST).

#### Scenario: 벤치 하나만 원본

- **WHEN** 월드 점토가 보통일 때 운영자가 벤치 하나의 점토를 원본으로 덮어쓴다
- **THEN** 그 벤치만 원래 모양이고 점토 항목에 덮어쓰기 표시와 되돌리기가 보인다
