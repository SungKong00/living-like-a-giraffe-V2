# Spec Delta

## ADDED Requirements

### Requirement: 월드 기본 점토 설정

월드 패널은 점토 강도·눌림 깊이·자국 크기를 원본·약하게·보통·강하게 단계와 세부 값으로 바꿀 수 있어야 한다(MUST). 덮어쓰지 않은 모든 가구와 캐릭터는 이 값을 따른다. 편집 장면은 값을 바꾸는 동안 바로 반영한다(MUST).

#### Scenario: 월드 단계 변경

- **WHEN** 운영자가 월드 점토를 보통에서 강하게로 바꾼다
- **THEN** 덮어쓰지 않은 가구가 모두 강하게 바뀌고 초안의 `defaults.clay`에 저장된다

### Requirement: 개체별 점토 덮어쓰기

방·가구·캐릭터 편집기는 그 대상의 점토 값을 자기 종류의 기본값과 다르게 정할 수 있어야 하고, 덮어쓴 항목을 표시하며 월드 값으로 되돌릴 수 있어야 한다(MUST). 개체를 삭제하거나 Blender 인계로 사라지면 그 덮어쓰기도 남지 않아야 한다(MUST).

#### Scenario: 벤치 하나만 원본

- **WHEN** 오브젝트 점토가 보통일 때 운영자가 벤치 하나의 점토를 원본으로 덮어쓴다
- **THEN** 그 벤치만 원래 모양이고 점토 항목에 덮어쓰기 표시와 되돌리기가 보인다

### Requirement: 캐릭터 크기에 맞는 점토 조형

캐릭터의 굴곡과 눌림 깊이·자국 크기는 모델 치수에 비례해야 한다(MUST). 기린 비교 시안은 약한 단계에서 시작하고, 편집기와 같은 변형 범위를 써야 한다(MUST).

#### Scenario: 크기가 다른 기린

- **WHEN** 같은 기린을 서로 다른 단위로 내보내 같은 키로 배치하고 같은 점토 값을 적용한다
- **THEN** 키에 대한 자국의 크기와 깊이 비율이 같고, 강한 단계에서도 얼굴과 발바닥을 보호한다

### Requirement: 월드 전체의 점토 꿈틀거림

스튜디오는 월드에 하나의 재생 스위치와 강도 조절기를 제공해야 한다(MUST). 점토 표면을 선택하면 자세와 윤곽을 유지하며 둥근 요철의 음영이 움직이고 v1 화면 일렁임은 전체 3D 화면을 굴절시킨다. 두 방식 모두 움직임을 0.2초 간격으로 갱신하며 다시 켜면 마지막 강도를 사용해야 한다(MUST).

#### Scenario: 꿈틀거림 저장과 발행

- **WHEN** 운영자가 월드에서 꿈틀거림을 켜고 강도를 조절한다
- **THEN** 장면에 즉시 보이며 초안을 다시 열어도 설정이 유지되고, 발행 후에는 관람 장면에도 같은 설정이 적용된다

#### Scenario: 시안에서 꿈틀거림 비교

- **WHEN** 독립 점토 시안에서 꿈틀거림을 켜고 벤치와 기린을 번갈아 고른다
- **THEN** 같은 강도가 오른쪽 시안에만 적용되고, 점토 표면 방식에서는 기린의 눈·코·입이 유지된다. 비교 조작은 월드 초안을 변경하지 않는다

#### Scenario: 빗금 질감만 사용

- **WHEN** 운영자가 꿈틀거림을 끈 채 세부 조절에서 빗금 질감을 높인다
- **THEN** 정지한 빗금이 보이고, 움직임 설정과 독립적으로 저장된다
