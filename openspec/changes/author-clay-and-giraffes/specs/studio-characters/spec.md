# Spec Delta

## ADDED Requirements

### Requirement: 캐릭터 자료실

운영자는 리깅된 캐릭터 모델 여러 개와 동작 파일 여러 개를 GLB로 올리고 지울 수 있어야 한다(MUST). 리라지 네발·두발 점토 기린은 지울 수 없는 기본 모델로 항상 보여야 한다(MUST). 서버는 스킨이 없는 모델, 애니메이션이 없는 동작, 어느 모델의 관절과도 맞지 않는 동작을 이유와 함께 거부한다(MUST). 자료실은 동작 파일마다 어느 모델과 맞는지 보여준다(MUST).

#### Scenario: 두발 기린 추가와 편집

- **WHEN** 운영자가 월드 기본 동작이 없는 방에 두발 점토 기린을 추가한다
- **THEN** 옷 없는 두발 점토 기린이 전용 걷기를 재생하고, 선택한 개체의 속도와 체형을 편집할 수 있다

#### Scenario: 맞지 않는 동작 파일

- **WHEN** 자료실의 어느 모델과도 다른 뼈대로 만든 동작 파일을 올린다
- **THEN** 업로드가 거부되고 캐릭터 모델의 관절 이름과 맞지 않는다는 안내가 보인다

#### Scenario: 쓰는 중인 모델 삭제

- **WHEN** 캐릭터가 쓰는 모델을 자료실에서 지운다
- **THEN** 지우지 못하고 그 모델을 쓰는 캐릭터 수가 안내된다. 다른 경로로 모델을 열 수 없게 된 캐릭터는 자리 표시로 보이며 편집기가 다른 모델을 고르라고 안내한다

### Requirement: 캐릭터 모델 관리

운영자는 자료실에서 모델을 골라 이름과 기본 키를 바꾸고, 새 버전 파일로 교체할 수 있어야 한다(MUST). 교체해도 그 모델을 쓰는 캐릭터는 모델·위치·방향·크기·체형을 유지하고, 모델에 들어 있던 동작을 쓰던 캐릭터는 새 파일의 같은 이름 동작을 재생해야 한다(MUST). 초안이나 게시본의 캐릭터·월드 기본값이 쓰는 모델과 동작 파일은 자료실에서 뺄 수 없고, 이유를 보여야 한다(MUST). 뺀 모델은 같은 파일을 다시 올리면 돌아와야 한다(MUST). 기본 모델은 이름과 기본 키만 바꿀 수 있다.

#### Scenario: 모델 새 버전 올리기

- **WHEN** 캐릭터 둘이 쓰는 모델에 새 버전 파일을 올린다
- **THEN** 두 캐릭터가 같은 자리·방향·크기로 새 파일을 보여주고, 모델 이름과 기본 키는 그대로이며, 모델에 들어 있던 동작을 쓰던 캐릭터는 새 파일의 같은 동작을 재생한다

#### Scenario: 쓰는 중인 모델 빼기

- **WHEN** 캐릭터가 쓰는 모델을 자료실에서 빼려 한다
- **THEN** 빼기 단추가 꺼져 있고 그 모델을 쓰는 캐릭터 수와 먼저 모델을 바꾸라는 안내가 보이며, 서버도 요청을 거부한다

### Requirement: 모델 기본 키

자료실의 모델마다 크기 100%인 캐릭터가 보일 기본 키(m)가 있어야 한다(MUST). 처음 올리면 모델 파일에서 잰 키가 기본 키다. 캐릭터의 크기는 기본 키에 곱하는 배율이고, 편집기는 배율과 함께 실제 키를 보여야 한다(MUST). 기본 키를 바꾸면 그 모델의 캐릭터가 모두 새 키를 따른다(MUST).

#### Scenario: 기본 키 바꾸기

- **WHEN** 파일 그대로 4.13m인 기본 기린의 기본 키를 2.4m로 바꾼다
- **THEN** 크기 100%인 기린이 2.4m로 보이고 크기 150%인 기린은 3.6m로 보이며, 기본 키 항목은 파일 값을 덮어썼다고 표시하고 되돌릴 수 있다

### Requirement: 캐릭터 착용물

자료실은 모델의 착용물(`wearable` 사용자 속성이 있거나 이름이 `Wear.`로 시작하는 노드)을 목록으로 보여야 한다(MUST). 운영자는 캐릭터마다 착용물을 켜고 끌 수 있어야 하며, 새 캐릭터는 착용물 없이 시작한다(MUST). 기본 리라지 기린은 케이프와 꽃을 착용물로 갖는다.

#### Scenario: 케이프 입히기

- **WHEN** 기린 두 마리 중 하나의 편집기에서 케이프를 켠다
- **THEN** 그 기린만 케이프를 입고, 체형을 바꾸면 케이프도 몸에 맞춰진다

### Requirement: 모델별 점토 얼굴 보호

모델에 `_CLAY_PROTECT` 정점 속성(0~1)이 있으면 점토 조형과 점토 꿈틀거림이 그 값만큼 정점을 원래 자리에 두어야 한다(MUST). 속성이 없는 모델은 리라지 기린과 같은 골격일 때만 머리 높이 기준으로 얼굴을 보호하고, 그 밖의 모델은 보호하지 않는다(MUST). 캐릭터 편집기와 자료실은 어떤 보호가 적용되는지 보여준다(MUST).

#### Scenario: 정점 그룹으로 표시한 모델

- **WHEN** Blender에서 `clay_protect` 정점 그룹을 칠하고 `scripts/clay-protect-attribute.py`로 내보낸 모델을 올리고 캐릭터 점토를 강하게 한다
- **THEN** 표시한 정점은 움직이지 않고 나머지 몸만 점토처럼 눌리며, 편집기에 모델의 정점 그룹으로 보호한다고 보인다

### Requirement: 캐릭터 추가와 배치

운영자는 추가 메뉴에서 모델을 골라 캐릭터를 추가하고, 포인터를 따라오는 캐릭터를 방 바닥에 클릭해 놓을 수 있어야 한다(MUST). 같은 메뉴에서 새 모델을 올려 바로 추가할 수 있어야 한다(MUST). 놓은 캐릭터는 장면에서 끌어 같은 방이나 다른 방으로 옮기고, 방향키·회전 단축키·복제 단축키를 가구와 같은 뜻으로 쓸 수 있어야 한다(MUST). 놓을 지점은 포인터 아래 방 바닥이며, 벽이나 소품이 포인터를 가려도 바닥 위에 놓인다(MUST).

#### Scenario: 모델을 골라 원하는 자리에 놓기

- **WHEN** 추가 메뉴에서 리라지 점토 기린을 고르고 포인터를 사우나 바닥 위로 옮긴 뒤 클릭한다
- **THEN** 캐릭터가 포인터를 따라 움직이다가 클릭한 바닥에 놓이고, 초안에 사우나와 그 위치, 모델 `riragi`가 저장된다

#### Scenario: 놓기를 취소

- **WHEN** 캐릭터를 추가한 뒤 놓기 상태에서 Esc를 누른다
- **THEN** 캐릭터는 그 방의 다른 캐릭터와 겹치지 않는 빈 자리에 남는다

### Requirement: 캐릭터 조절과 동작 설정

운영자는 캐릭터 편집기에서 이름·모델·방·위치·높이·방향·크기·동작·속도를 바꿀 수 있어야 한다(MUST). 동작 목록에는 그 캐릭터의 모델과 맞는 동작만 보여야 한다(MUST). 월드 패널의 기본 동작과 속도를 따르지 않는 값은 덮어쓰기로 표시하고 되돌릴 수 있어야 한다(MUST). 편집 장면은 선택한 동작을 반복 재생하고 캐릭터를 눌러 선택할 수 있어야 한다(MUST). 같은 동작을 재생하는 캐릭터들은 캐릭터마다 정해진 서로 다른 시점에서 시작해야 한다(MUST). 동작은 여러 개(최대 8개)를 고를 수 있고, 차례대로 또는 무작위로 하나씩 이어 재생하며 사이를 섞는다(MUST). 순서도 월드 기본값과 캐릭터별 덮어쓰기를 따른다.

#### Scenario: 캐릭터 하나만 다른 동작

- **WHEN** 월드 기본 동작이 걷기일 때 캐릭터 하나의 동작을 풀 뜯기로 바꾼다
- **THEN** 그 캐릭터만 풀 뜯기를 재생하고 동작 항목에 덮어쓰기 표시가 보이며, 되돌리면 다시 걷기를 재생한다

#### Scenario: 동작 여러 개

- **WHEN** 캐릭터 동작에 둘러보기와 걷기를 고르고 순서를 무작위로 한다
- **THEN** 캐릭터가 두 동작 중 하나를 끝까지 재생한 뒤 다른 동작으로 넘어가고, 동작 목록과 순서가 초안에 저장된다

#### Scenario: 복제한 캐릭터

- **WHEN** 동작을 재생하는 캐릭터를 복제한다
- **THEN** 두 캐릭터가 같은 동작을 서로 다른 시점에서 재생하고, 다시 열어도 각자 같은 시점에서 시작한다

#### Scenario: 모델 바꾸기

- **WHEN** 캐릭터 편집기에서 모델을 다른 모델로 바꾼다
- **THEN** 장면의 그 캐릭터가 같은 자리·방향·크기로 새 모델을 보여주고, 동작 목록이 새 모델에 맞는 동작으로 바뀐다

### Requirement: 선택 모델 미리보기

운영자가 가구나 캐릭터를 선택하면 속성 패널 위에 선택한 모델을 단독으로 표시해야 한다(MUST). 미리보기의 드래그와 방향키는 모델을 보는 각도만 바꾸며 배치 방향과 편집 기록은 유지해야 한다(MUST).

#### Scenario: 캐릭터 둘러보기

- **WHEN** 운영자가 기린을 선택해 미리보기를 돌린 뒤 체형을 바꾼다
- **THEN** 미리본 각도에서 새 체형이 보이고 장면 속 기린은 원래 방향에 서 있다. 배치 방향을 편집해도 미리보기는 모델의 같은 면을 보여준다

### Requirement: 개체별 기린 체형

운영자는 리라지 기린과 같은 관절 구성의 모델에서 목 길이·머리 크기·다리 길이·몸통 크기를 캐릭터마다 독립적으로 편집하고 저장할 수 있어야 한다(MUST). 기존 캐릭터의 기준 배율은 100%다. 관절 구성이 다른 모델의 편집기는 체형을 지원하지 않는다고 표시한다(MUST).

#### Scenario: 귀와 주둥이 조절

- **WHEN** 운영자가 두발 기본 기린의 귀 크기나 주둥이 길이를 조절한다
- **THEN** 귀는 양쪽 귀 뿌리에서, 주둥이는 눈 앞쪽에서 변형되고, 걷기를 재생하거나 저장 후 다시 열어도 그 비율을 유지한다. 지원 관절이 있는 모델에 해당 조절 항목이 표시된다.

#### Scenario: 같은 방에 서로 다른 기린 배치

- **WHEN** 운영자가 두 기린을 추가한 뒤 한 기린의 체형을 바꾸고 초안을 다시 연다
- **THEN** 두 기린은 각자 정한 체형을 유지하고, 골격 동작·착용물은 그 개체의 비율을 따른다

#### Scenario: 몸통 크기 조절

- **WHEN** 운영자가 몸통 크기만 바꾼다
- **THEN** 몸통의 폭·높이·앞뒤 길이와 목 굵기가 같은 비율로 바뀌고, 머리 크기와 목·다리 길이, 서 있는 발굽의 높이는 유지된다. 몸에 입힌 옷은 새 크기를 따른다.

### Requirement: 기린 이름으로 저장한 자료 읽기

기린이라 부르던 때 저장한 초안(`giraffes`, `defaults.giraffe`, 점토 기본값 `giraffes`)과 자료실(`giraffes/` 폴더, 모델 하나만 있던 목록)은 캐릭터로 읽혀야 한다(MUST).

#### Scenario: 이전 초안 열기

- **WHEN** 기린 두 마리와 기린 점토 기본값이 저장된 초안을 스튜디오에서 연다
- **THEN** 두 캐릭터와 캐릭터 점토 기본값으로 보이고, 다음 저장부터 새 이름으로 저장된다. 모델을 정하지 않았던 캐릭터는 예전에 올린 모델로 보인다

### Requirement: 클라우드 캐릭터 자료실

클라우드 스튜디오에서도 로그인한 편집자는 독립 모델과 동작 GLB를 등록하고 관리할 수 있어야 한다(MUST). 공개 전에는 편집자만 등록한 파일을 읽을 수 있어야 한다(MUST).

#### Scenario: 동작 파일을 등록하고 배치

- **WHEN** 편집자가 모델과 골격이 맞는 동작을 올리고 방에 배치한 캐릭터의 체형과 동작을 저장한다
- **THEN** 다시 연 스튜디오에서 같은 모델·체형·동작이 재현되고, 방문자는 해당 개정의 공개 승인 이후에 그 모델과 동작을 읽는다

#### Scenario: 클라우드 자료실 정리 후 버전 복원

- **WHEN** 운영 자료실에서 쓰지 않는 모델과 중복 동작을 제외한 뒤 이전 배치를 다시 연다
- **THEN** 현재 추가 메뉴에는 현재 자료만 나타나며, 기록에서 참조하는 이전 모델과 동작은 해당 배치를 미리 보거나 복원할 때 읽을 수 있다.
