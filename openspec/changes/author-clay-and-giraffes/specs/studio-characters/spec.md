# Spec Delta

## ADDED Requirements

### Requirement: 캐릭터 자료실

운영자는 리깅된 캐릭터 모델 여러 개와 동작 파일 여러 개를 GLB로 올리고 지울 수 있어야 한다(MUST). 리라지 점토 기린은 지울 수 없는 기본 모델로 항상 보여야 한다(MUST). 서버는 스킨이 없는 모델, 애니메이션이 없는 동작, 어느 모델의 관절과도 맞지 않는 동작을 이유와 함께 거부한다(MUST). 자료실은 동작 파일마다 어느 모델과 맞는지 보여준다(MUST).

#### Scenario: 맞지 않는 동작 파일

- **WHEN** 자료실의 어느 모델과도 다른 뼈대로 만든 동작 파일을 올린다
- **THEN** 업로드가 거부되고 캐릭터 모델의 관절 이름과 맞지 않는다는 안내가 보인다

#### Scenario: 쓰는 중인 모델 삭제

- **WHEN** 캐릭터가 쓰는 모델을 자료실에서 지운다
- **THEN** 지우기 전에 쓰는 캐릭터가 있다고 확인을 받고, 지운 뒤 그 캐릭터는 자리 표시로 보이며 편집기가 다른 모델을 고르라고 안내한다

### Requirement: 캐릭터 추가와 배치

운영자는 추가 메뉴에서 모델을 골라 캐릭터를 추가하고, 포인터를 따라오는 캐릭터를 방 바닥에 클릭해 놓을 수 있어야 한다(MUST). 같은 메뉴에서 새 모델을 올려 바로 추가할 수 있어야 한다(MUST). 놓은 캐릭터는 장면에서 끌어 같은 방이나 다른 방으로 옮기고, 방향키·회전 단축키·복제 단축키를 가구와 같은 뜻으로 쓸 수 있어야 한다(MUST). 놓을 지점은 포인터 아래 방 바닥이며, 벽이나 소품이 포인터를 가려도 바닥 위에 놓인다(MUST).

#### Scenario: 모델을 골라 원하는 자리에 놓기

- **WHEN** 추가 메뉴에서 리라지 점토 기린을 고르고 포인터를 사우나 바닥 위로 옮긴 뒤 클릭한다
- **THEN** 캐릭터가 포인터를 따라 움직이다가 클릭한 바닥에 놓이고, 초안에 사우나와 그 위치, 모델 `riragi`가 저장된다

#### Scenario: 놓기를 취소

- **WHEN** 캐릭터를 추가한 뒤 놓기 상태에서 Esc를 누른다
- **THEN** 캐릭터는 그 방의 다른 캐릭터와 겹치지 않는 빈 자리에 남는다

### Requirement: 캐릭터 조절과 동작 설정

운영자는 캐릭터 편집기에서 이름·모델·방·위치·높이·방향·크기·동작·속도를 바꿀 수 있어야 한다(MUST). 동작 목록에는 그 캐릭터의 모델과 맞는 동작만 보여야 한다(MUST). 월드 패널의 기본 동작과 속도를 따르지 않는 값은 덮어쓰기로 표시하고 되돌릴 수 있어야 한다(MUST). 편집 장면은 선택한 동작을 반복 재생하고 캐릭터를 눌러 선택할 수 있어야 한다(MUST).

#### Scenario: 캐릭터 하나만 다른 동작

- **WHEN** 월드 기본 동작이 걷기일 때 캐릭터 하나의 동작을 풀 뜯기로 바꾼다
- **THEN** 그 캐릭터만 풀 뜯기를 재생하고 동작 항목에 덮어쓰기 표시가 보이며, 되돌리면 다시 걷기를 재생한다

#### Scenario: 모델 바꾸기

- **WHEN** 캐릭터 편집기에서 모델을 다른 모델로 바꾼다
- **THEN** 장면의 그 캐릭터가 같은 자리·방향·크기로 새 모델을 보여주고, 동작 목록이 새 모델에 맞는 동작으로 바뀐다

### Requirement: 개체별 기린 체형

운영자는 리라지 기린과 같은 관절 구성의 모델에서 목 길이·머리 크기·다리 길이·몸통 크기를 캐릭터마다 독립적으로 편집하고 저장할 수 있어야 한다(MUST). 기존 캐릭터의 기준 배율은 100%다. 관절 구성이 다른 모델의 편집기는 체형을 지원하지 않는다고 표시한다(MUST).

#### Scenario: 같은 방에 서로 다른 기린 배치

- **WHEN** 운영자가 두 기린을 추가한 뒤 한 기린의 체형을 바꾸고 초안을 다시 연다
- **THEN** 두 기린은 각자 정한 체형을 유지하고, 골격 동작·착용물은 그 개체의 비율을 따른다

#### Scenario: 몸통 크기 조절

- **WHEN** 운영자가 몸통 크기만 바꾼다
- **THEN** 몸통의 폭·높이·앞뒤 길이와 목 굵기가 같은 비율로 바뀌고, 머리 크기와 목·다리 길이, 서 있는 발굽의 높이는 유지된다. 몸에 입힌 옷은 새 크기를 따른다.

### Requirement: 기린 이름으로 저장한 자료 읽기

기린이라 부르던 때 저장한 초안(`giraffes`, `defaults.giraffe`, 점토 기본값 `giraffes`)과 자료실(`giraffes/` 폴더, 모델 하나만 있던 목록)은 캐릭터로 읽혀야 한다(MUST).

#### Scenario: 이전 초안 열기

- **WHEN** 기린 두 마리와 기린 점토 기본값이 저장된 초안을 스튜디오에서 연다
- **THEN** 두 캐릭터와 캐릭터 점토 기본값으로 보이고, 다음 저장부터 새 이름으로 저장된다. 모델을 정하지 않았던 캐릭터는 예전에 올린 모델로 보인다
