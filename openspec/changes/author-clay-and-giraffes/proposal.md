# Proposal

## Why

운영자는 점토처럼 눌리고 굽은 질감을 월드 전체의 기본 외형으로 정하고, 특정 가구만 더 강하거나 약하게 바꾸고 싶어 한다. 점토 조형은 월드에 저장되지 않는다. 또 리깅된 캐릭터(기본은 리라지 점토 기린)를 월드에 여러 개 놓고, 그 뼈대에 맞춰 만든 동작 파일을 올려 움직이게 하려 한다. 기린 외의 캐릭터도 놓을 수 있도록 편집 대상의 이름은 캐릭터로 한다. 현재 기린은 운동회 방에 합쳐진 정지 모형뿐이다.

## What Changes

- 초안에 월드 기본 점토 설정(강도·눌림 깊이·자국 크기)과 개체별 점토 덮어쓰기를 저장한다. 월드 패널에서 단계와 세부 값을 바꾸고, 가구·캐릭터 편집기에서 그 개체만 덮어쓰거나 월드 값으로 되돌린다. 편집 장면은 바뀐 값을 바로 보여준다.
- 월드 표면 요철의 꿈틀거림을 켜고 강도를 정한다. 움직임은 편집과 발행 후 관람 장면에서 같은 방식으로 재생한다.
- 캐릭터 자료실을 둔다. 기본 리라지 점토 기린에 더해 리깅된 모델(GLB, 스킨 포함)과 동작 파일(GLB, 애니메이션 포함)을 여러 개 올리고 지운다. 서버는 동작이 어느 모델의 뼈대 이름과 맞는지 검사하고 모델별 일치 수를 알려준다.
- 초안에 캐릭터 목록을 저장한다. 추가 메뉴에서 모델을 골라 포인터로 방 바닥에 놓고, 장면에서 끌어 옮기며, 편집기에서 모델·위치·방향·크기·개체별 체형·동작·속도를 바꾼다. 월드 패널에서 기본 동작과 속도를 정하고, 캐릭터마다 덮어쓰거나 되돌린다. 편집 장면에서 캐릭터를 선택하고 동작을 재생한다. 기린이라 부르던 때 저장한 초안과 자료실은 새 이름으로 읽는다.

## Capabilities

### New Capabilities

- `studio-clay`: 월드 기본 점토 설정과 개체별 덮어쓰기.
- `studio-characters`: 캐릭터 자료실, 캐릭터 배치·조절, 동작 설정.

### Modified Capabilities

없음. 기존 가구·조명 저장 형식과 Blender 인계 병합은 바꾸지 않는다.

## Impact

초안 JSON에 선택 항목 `defaults`, `overrides`, `characters`를 더하고 서버 검증을 넓힌다. 캐릭터 자료 업로드·조회 API(`/api/admin/characters`)와 저장 디렉터리 `characters/`를 추가한다. 스튜디오의 목록·속성 패널·편집 장면에 점토와 캐릭터를 더하고, 디자인 시스템에 `FileList`를 더한다. 정적 점토 조형과 배치한 캐릭터의 관람 표시, Blender 굽기는 다음 단계다.
