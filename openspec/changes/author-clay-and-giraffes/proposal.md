# Proposal

## Why

운영자는 점토처럼 눌리고 굽은 질감을 월드 전체의 기본 외형으로 정하고, 특정 가구만 더 강하거나 약하게 바꾸고 싶어 한다. 지금 점토 조형은 벤치와 기린 두 대상만 비교하는 별도 시안이라 월드에 저장되지 않는다. 또 리깅된 기린을 월드에 여러 마리 놓고, 그 뼈대에 맞춰 만든 동작 파일을 올려 움직이게 하려 한다. 현재 기린은 운동회 방에 합쳐진 정지 모형뿐이다.

## What Changes

- 초안에 월드 기본 점토 설정(강도·눌림 깊이·자국 크기)과 개체별 점토 덮어쓰기를 저장한다. 월드 패널에서 단계와 세부 값을 바꾸고, 가구·기린 편집기에서 그 개체만 덮어쓰거나 월드 값으로 되돌린다. 편집 장면은 바뀐 값을 바로 보여준다.
- 기린 자료실을 둔다. 리깅된 기린 모델(GLB, 스킨 포함) 하나와 동작 파일(GLB, 애니메이션 포함) 여러 개를 올리고 지운다. 서버는 동작이 모델 뼈대 이름과 맞는지 검사한다.
- 초안에 기린 목록을 저장한다. 추가 메뉴에서 기린을 방에 놓고 위치·방향·크기·동작·속도를 바꾼다. 월드 패널에서 기본 동작과 속도를 정하고, 기린마다 덮어쓰거나 되돌린다. 편집 장면에서 기린을 선택하고 동작을 재생한다.

## Capabilities

### New Capabilities

- `studio-clay`: 월드 기본 점토 설정과 개체별 덮어쓰기.
- `studio-giraffes`: 기린 자료실, 기린 배치·조절, 동작 설정.

### Modified Capabilities

없음. 기존 가구·조명 저장 형식과 Blender 인계 병합은 바꾸지 않는다.

## Impact

초안 JSON에 선택 항목 `defaults`, `overrides`, `giraffes`를 더하고 서버 검증을 넓힌다. 기린 자료 업로드·조회 API와 저장 디렉터리 `giraffes/`를 추가한다. 스튜디오의 목록·속성 패널·편집 장면에 점토와 기린을 더한다. 관람 화면과 Blender 굽기에는 이번 변경에서 반영하지 않는다(설계의 다음 단계 참고).
