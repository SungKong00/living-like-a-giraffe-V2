# Design

## Context

스튜디오는 관람 화면과 같은 Babylon.js 장면(`web/scene.js`)을 편집 모드로 열고, `web/studio.js` 한 파일이 목록·속성·인계·발행을 모두 만든다. 카메라는 왼쪽 드래그로 제한된 회전을 하고 화면 이동이 꺼져 있다. 같은 왼쪽 드래그를 `GizmoManager`가 함께 쓰기 때문에 얇은 화살표를 정확히 누르지 않으면 카메라가 돈다. 속성 패널은 모든 변경 뒤 통째로 다시 만들어진다. 저장 형식과 서버 검증은 [월드 배치 명세](../preserve-world-layout/specs/world-layout/spec.md)를 따르며 이번 변경에서 바꾸지 않는다.

## Goals / Non-Goals

**Goals:**

- 왼쪽 버튼은 대상 조작, 오른쪽 버튼은 시점 회전, 휠은 확대로 입력 역할을 나눈다.
- 편집 연산을 순수 함수로 분리해 Node 테스트로 검증한다.
- 기존 배치 JSON·API·발행 상태 기계를 그대로 사용한다.

**Non-Goals:**

- 여러 가구 동시 선택과 정렬 도구.
- 높이(Y) 방향 끌기. 높이는 숫자로만 바꾼다.
- 휴대폰 편집. 휴대폰은 기존처럼 관람만 제공한다.

## Decisions

### 기즈모 대신 바닥 평면 끌기

가구를 누르면 가구 기준점 높이의 수평면과 포인터 광선의 교점을 따라 움직인다. 끌기 시작점과 가구 기준점의 차이를 유지해 잡은 위치가 튀지 않게 한다. 방 좌표에서 0.25m 격자에 맞추고 Alt를 누르면 격자를 끈다. 정사영 사선 카메라에서는 Y축 화살표가 쓸모없고 X·Z 화살표가 작아 잡기 어려웠다. 평면 끌기는 방 배치 도구에서 흔한 방식이고 클릭 영역 표시에도 같은 방식을 쓸 수 있다. 회전은 떠 있는 도구·Q/E 키·슬라이더로 15° 단위로 처리한다.

### 다른 방으로 놓기

끌기를 놓을 때 교점이 현재 방 바닥 범위 밖이고 다른 방 범위 안이면 소속 방을 바꾼다. 새 지역 변환은 `가구 지역 행렬 × 이전 방 월드 행렬 × 새 방 월드 행렬의 역`을 분해해 구한다. 방 범위는 장면을 연 직후 각 방 계층의 바닥 경계로 한 번 계산한다. 속성 패널에서 방을 직접 바꾸면 새 방의 기준점 위에 놓는다.

### 선택 강조와 떠 있는 도구

`HighlightLayer`로 선택과 마우스 오버를 구분해 표시한다. 엔진은 이미 스텐실을 켜고 있다. 선택 가구 경계 상자의 위쪽 중심을 매 프레임 화면에 투영해 HTML 도구 막대를 띄운다.

### 편집 연산과 자동 저장 분리

`web/edit-ops.js`는 복제·추가·삭제(연결 영역 포함)·방 이동·회전·페이지 삭제를 레이아웃 사본에 적용하는 순수 함수로 둔다. `web/autosave.js`는 변경 뒤 짧게 기다렸다 한 번에 하나씩 저장하고 409를 충돌 상태로 바꾼다. 끌기와 슬라이더는 진행 중에 장면만 갱신하고 끝날 때 편집 이력 한 건을 남긴다.

### 화면 구성

상단에는 저장 상태·되돌리기·미리보기·인계·발행만 둔다. 왼쪽은 `배치`·`페이지` 탭, 가운데 장면 위에는 시점 도구와 도움말, 오른쪽은 선택 대상의 속성만 둔다. 속성 패널을 다시 그릴 때 `data-key`로 포커스와 커서 위치를 복원한다. 발행은 상단 버튼에 붙은 창에서 단계·상태를 보여주고, 인계는 모달 창에서 단계별로 진행한다.

### 가구 추가 목록

서버의 편집 초안 응답에 모델 카탈로그의 가구 종류와 대표 이름을 `kinds`로 더한다. 새 가구는 선택한 방 또는 첫 방의 기준점에 기본 옵션으로 놓는다. 서버는 기존처럼 카탈로그 종류만 허용한다.

## Risks / Trade-offs

- [자동 저장이 준비 중인 검토 결과를 무효화한다] → 발행 창과 상단 발행 버튼에 취소 사실을 표시하고 다시 준비하게 한다. 저장 시점에 검토를 지키는 방식은 서버 상태 기계를 바꿔야 해서 제외했다.
- [방 경계를 계층 경계로 근사한다] → 방 사이 경계 근처에서는 놓은 뒤 소속 방이 속성 패널에 보이므로 즉시 확인·변경할 수 있다.
- [끌기 중 매 프레임 갱신 비용] → 끌기 중에는 노드 변환만 바꾸고 표시·저장은 놓을 때 한 번 갱신한다.
