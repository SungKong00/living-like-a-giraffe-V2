# Proposal

## Why

PC 스튜디오에서 가구를 고르고 옮기는 기본 조작이 동작하지 않는다. 이동 기즈모를 끌면 카메라가 돌아가고, 선택한 가구가 화면에 표시되지 않으며, 입력 칸을 고칠 때마다 패널이 다시 그려져 다음 칸으로 넘어갈 수 없다. 선택과 무관한 Blender 인계·공개 관리가 속성 패널 아래에 섞여 있어 운영자가 어디서 무엇을 해야 하는지 알기 어렵다.

## What Changes

- 장면에서 가구를 직접 끌어 방 바닥 위로 옮긴다. 다른 방으로 끌어다 놓으면 그 방으로 옮겨진다. 빈 곳을 끌면 화면이 이동하고 오른쪽 버튼으로 끌면 정해진 범위 안에서 시점이 회전한다. 기존 이동·회전·크기 기즈모는 제거한다.
- 선택한 가구를 강조 표시하고 그 위에 복제·회전·삭제 도구를 띄운다. 키보드로 복제·삭제·회전·미세 이동·되돌리기를 할 수 있다.
- 왼쪽 목록은 방별로 가구와 클릭 영역을 묶고 검색과 가구 추가를 제공한다. 행사 페이지는 별도 탭에서 관리한다.
- 오른쪽 속성 패널은 선택 대상에 맞는 항목만 보여준다. 위치·회전·크기는 슬라이더와 숫자로, 색상은 견본으로, 표면은 버튼으로 바꾼다. 연결된 클릭 영역을 함께 보여준다. 입력한 값이 저장 규칙에 맞지 않으면 그 자리에서 알린다.
- 클릭 영역 표시를 끌어 위치를 옮긴다. 가구를 삭제하면 연결된 클릭 영역도 함께 지우고 되돌릴 수 있다. 행사 페이지를 삭제할 수 있다.
- 초안을 편집 직후 자동 저장하고 저장 상태를 상단에 표시한다.
- 발행과 Blender 인계를 상단의 별도 창으로 옮긴다. 발행 창은 구운 결과 준비→검토→공개 단계와 현재 상태를 보여준다.

## Capabilities

### New Capabilities

- `studio-editing`: PC 스튜디오에서 운영자가 가구·클릭 영역·행사 페이지를 선택하고 조작·저장·발행하는 편집 경험.

### Modified Capabilities

없음. 배치 데이터 계약, 서버 검증, 재인계 병합, 발행 단계는 [진행 중인 월드 배치 변경](../preserve-world-layout/proposal.md)의 명세를 그대로 따른다.

## Impact

`web/studio.js`와 스튜디오 화면 스타일을 새로 구성하고, `web/scene.js`의 편집 모드 카메라·선택 처리를 바꾼다. 서버의 편집 초안 응답에 추가 가능한 가구 종류 목록을 더한다. 관람 화면과 저장 형식, 발행 API는 바뀌지 않는다. 브라우저 테스트와 월드 자산 안내의 스튜디오 사용법을 갱신한다.
