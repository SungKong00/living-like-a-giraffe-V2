# Tasks

## 1. 편집 연산과 저장

- [x] 1.1 복제·추가·삭제(연결 영역 포함)·방 이동·회전·페이지 삭제를 순수 함수로 구현한다. `npm test`에서 원본 보존·새 ID·연결 영역 복구를 확인한다.
- [x] 1.2 자동 저장 대기열과 충돌 상태를 구현한다. `npm test`에서 연속 변경 병합, 순차 저장, 409 충돌 전환을 확인한다.
- [x] 1.3 편집 초안 응답에 가구 종류 목록을 더한다. 브라우저 테스트에서 가구 추가 목록에 카탈로그 종류가 보이는지 확인한다.

## 2. 장면 조작

- [x] 2.1 편집 모드 카메라를 오른쪽 버튼 회전·왼쪽 빈 곳 화면 이동·휠 확대로 나누고 기즈모를 제거한다. 브라우저에서 빈 바닥을 끌 때 가구 값이 바뀌지 않는지 확인한다.
- [x] 2.2 가구 선택 강조, 바닥 평면 끌기, 격자 맞춤, Esc 취소, 다른 방으로 놓기를 구현한다. 브라우저 테스트에서 끌기 후 위치가 바뀌고 되돌리기 한 번으로 복구되는지 확인한다.
- [x] 2.3 떠 있는 복제·회전·삭제 도구와 단축키를 구현한다. 브라우저 테스트에서 ⌘D 복제와 Delete 삭제·되돌리기를 확인한다.
- [x] 2.4 클릭 영역 표시 끌기를 구현한다. 브라우저에서 표시를 끈 뒤 상대 위치 값이 바뀌는지 확인한다.

## 3. 화면 구성

- [x] 3.1 상단 막대, 방별 목록·검색·가구 추가, 페이지 탭을 구성한다. 목록에서 가구를 누르면 장면이 그 가구로 이동하는지 확인한다.
- [x] 3.2 대상별 속성 패널과 빈 상태, 포커스 유지, 입력 검증 안내를 구현한다. 브라우저 테스트에서 Tab 연속 입력과 빈 외부 주소 안내를 확인한다.
- [x] 3.3 발행 창과 인계 창을 구현한다. 브라우저 테스트에서 구운 결과 준비→열기→공개와 준비 중 편집 시 취소 안내를 확인한다.
