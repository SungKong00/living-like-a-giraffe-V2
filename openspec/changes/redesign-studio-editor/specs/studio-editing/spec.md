# Spec Delta

## Purpose

운영자가 PC 스튜디오에서 가구와 클릭 영역을 장면 위에서 직접 고르고 옮기며, 옵션·콘텐츠 편집과 저장·발행을 한 화면에서 헷갈리지 않고 마칠 수 있게 한다.

## ADDED Requirements

### Requirement: 장면에서 직접 선택과 이동
스튜디오는 장면에서 누른 가구를 선택하고 강조 표시해야 한다(MUST). 가구를 끌면 소속 방 바닥과 같은 높이에서 포인터를 따라 움직이고 손을 뗄 때 한 번의 편집으로 기록해야 한다(MUST). 빈 곳을 끌면 화면이 이동하고 스튜디오의 오른쪽 끌기는 모든 방향 회전을 허용해야 한다(MUST). 가구나 방을 선택하면 속성 패널 상단에 선택한 대상의 현재 모습을 단독으로 표시해야 한다(MUST).

#### Scenario: 벤치를 끌어 옮기기
- **WHEN** 운영자가 사우나의 벤치를 눌러 창가 쪽으로 끌고 놓는다
- **THEN** 벤치가 강조된 채 놓은 위치에 남고, 높이와 회전은 유지되며, 되돌리기 한 번으로 원래 위치로 돌아간다

#### Scenario: 다른 방으로 옮기기
- **WHEN** 운영자가 가구를 사우나에서 운동회 방 바닥 위로 끌어다 놓는다
- **THEN** 가구의 소속 방이 운동회로 바뀌고 화면상 놓은 위치와 방향이 그대로 유지된다

#### Scenario: 끄는 도중 취소
- **WHEN** 가구를 끄는 중에 Esc를 누른다
- **THEN** 가구가 끌기 전 위치로 돌아가고 편집 기록이 생기지 않는다

#### Scenario: 빈 바닥 끌기
- **WHEN** 운영자가 가구가 없는 곳을 끈다
- **THEN** 가구는 움직이지 않고 화면만 이동한다

### Requirement: 선택 대상의 빠른 조작
선택한 가구에는 복제·회전·삭제 도구가 장면 위에 함께 표시되어야 한다(MUST). 같은 조작을 키보드로도 실행할 수 있어야 한다(MUST). 복제본은 새 ID와 원본의 옵션을 가지고 원본 옆에 놓이며 곧바로 선택된다. 가구를 삭제하면 그 가구에 붙은 클릭 영역도 함께 삭제되고 한 번의 되돌리기로 모두 복구된다(MUST).

#### Scenario: 복제 후 바로 옮기기
- **WHEN** 운영자가 벤치를 선택하고 복제를 누른 뒤 복제본을 끌어 옮긴다
- **THEN** 원본은 제자리에 남고 복제본만 옮겨지며 다시 열어도 두 벤치가 각자 위치에 있다

#### Scenario: 클릭 영역이 붙은 가구 삭제
- **WHEN** 행사 안내가 연결된 벤치를 삭제한 뒤 되돌린다
- **THEN** 삭제 시 벤치와 안내가 함께 사라지고, 되돌리면 둘 다 같은 연결로 복구된다

### Requirement: 대상별 속성 편집
속성 패널은 선택한 대상의 종류에 맞는 항목만 보여주고, 선택이 없을 때는 선택 방법을 안내해야 한다(MUST). 가구는 이름·방·위치·회전·크기·색상·표면과 연결된 클릭 영역을 편집한다. 색상과 표면은 해당 가구 종류의 허용값만 제시한다(MUST). 값을 입력한 뒤 다음 입력 칸으로 이동해도 포커스가 유지되어야 한다(MUST). 저장 규칙에 맞지 않는 이름·주소는 데이터에 반영하지 않고 입력 칸 옆에 이유를 보여준다(MUST).

#### Scenario: 연속 입력
- **WHEN** 운영자가 위치 X를 고치고 Tab으로 Z 칸에 이동해 값을 고친다
- **THEN** 두 값이 모두 반영되고 Z 칸에 포커스가 남는다

#### Scenario: 빈 외부 주소
- **WHEN** 클릭 영역의 연결을 외부 링크로 바꾸고 주소를 비워 둔다
- **THEN** 기존 연결이 유지되고 주소 입력 칸에 올바른 http·https 주소가 필요하다는 안내가 보인다

### Requirement: 클릭 영역과 페이지 관리
클릭 영역 표시를 끌어 기준 방이나 가구에 대한 상대 위치를 옮길 수 있어야 한다(MUST). 방이나 가구에서 새 클릭 영역을 추가하면 곧바로 선택되고, 연결할 페이지가 없으면 새 페이지를 만들어 연결할 수 있어야 한다(MUST). 행사 페이지는 별도 탭에서 추가·수정·삭제하며, 삭제할 때 연결된 클릭 영역의 수를 확인받는다(MUST).

#### Scenario: 클릭 영역 위치 맞추기
- **WHEN** 운영자가 벤치에 붙은 안내 표시를 벤치 끝으로 끈다
- **THEN** 안내의 상대 위치가 바뀌고 벤치를 다시 옮겨도 안내가 벤치 끝을 따라간다

### Requirement: 자동 저장과 상태 표시
스튜디오는 편집이 끝나면 초안을 자동으로 저장하고 저장 중·저장됨·실패 상태를 상단에 표시해야 한다(MUST). 다른 창의 저장과 충돌하면 덮어쓰지 않고 다시 열도록 안내한다(MUST). 저장하지 않은 변경이 있을 때 창을 닫으면 경고한다.

#### Scenario: 편집 후 새로고침
- **WHEN** 운영자가 가구 색을 바꾸고 저장 상태가 저장됨으로 바뀐 뒤 새로고침한다
- **THEN** 바꾼 색이 그대로 열린다

#### Scenario: 다른 창에서 먼저 저장
- **WHEN** 두 창에서 같은 초안을 열고 한 창에서 먼저 저장한 뒤 다른 창에서 편집한다
- **THEN** 뒤의 창은 저장하지 않고 충돌을 알리며 다시 열기를 제공한다

### Requirement: 발행과 인계 창
발행과 Blender 인계는 속성 패널과 분리된 창에서 제공해야 한다(MUST). 발행 창은 공개본과 초안의 일치 여부, 구운 결과 준비·검토·공개 단계와 진행 상태, 실패 사유와 재시도, 바로 발행, 직전 공개본 복원을 보여준다. 인계 창은 내려받기·업로드·충돌 선택·끊긴 연결 복구를 차례로 보여주고, 모든 충돌을 고르기 전에는 초안 적용을 막는다(MUST).

#### Scenario: 구운 결과로 공개
- **WHEN** 운영자가 발행 창에서 결과 준비를 누르고 다른 편집 없이 기다린다
- **THEN** 창에 준비 단계가 차례로 표시되고 검토 가능 상태에서 결과를 열어 공개할 수 있다

#### Scenario: 준비 중 편집
- **WHEN** 구운 결과를 준비하는 중에 가구를 옮긴다
- **THEN** 발행 창은 준비한 결과가 최신 초안과 맞지 않아 취소되었음을 알리고 다시 준비하도록 안내한다
