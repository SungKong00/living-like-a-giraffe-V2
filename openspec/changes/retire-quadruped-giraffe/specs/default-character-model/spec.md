# Spec Delta

## Purpose

스튜디오에 기본으로 들어 있는 캐릭터 모델과, 없어진 기본 모델을 가리키는 캐릭터를 읽는 방법을 정한다.

## ADDED Requirements

### Requirement: 기본 모델

스튜디오의 기본 모델은 두발 점토 기린 하나여야 한다(MUST). 네발 점토 기린은 자료실 목록, 추가 메뉴, 모델 선택에 나오지 않아야 한다(MUST).

#### Scenario: 새 데이터 폴더

- **WHEN** 운영자가 모델을 하나도 올리지 않은 스튜디오에서 추가 메뉴를 연다
- **THEN** 캐릭터 모델로 두발 점토 기린만 보인다

### Requirement: 없어진 기본 모델을 가리키는 캐릭터

모델을 정하지 않았거나 네발 점토 기린을 가리키는 캐릭터는 읽을 때 두발 점토 기린으로 옮겨야 한다(MUST). 캐릭터의 방·자리·방향·크기·이름·연결한 페이지는 유지해야 한다(MUST). 네발 기린 전용 동작과 착용물은 빼야 한다(MUST).

#### Scenario: 네발 기린이 놓인 초안

- **WHEN** 네발 기린 두 마리가 케이프를 입고 둘러보기 동작을 하던 초안을 연다
- **THEN** 같은 자리에 두발 기린 두 마리가 착용물 없이 월드 기본 동작으로 서 있다

#### Scenario: 이전 버전 복원

- **WHEN** 운영자가 네발 기린이 놓여 있던 이전 초안 버전을 복원한다
- **THEN** 복원한 초안의 그 캐릭터는 두발 기린이다
