- [x] 2.3 `web/studio-characters.js`가 경로 캐릭터를 시간표로 재생하게 한다. 캐릭터별 시계(`motionPhase` 시작, 움직일 때만 흐름), `setActive`의 멈춤·이어 가기, 클립을 읽기 전과 걷기 클립이 없을 때 첫 지점에 서기를 포함한다.

- [x] 4.1 `docs/world/README.md`의 캐릭터 항목에 경로 편집·지점별 할 일·걸음 길이·관람 재생을 적는다.
- [x] 4.2 `preserve-world-layout`의 "기기별 관람과 편집" 요구사항에서 이동 기린·배회 경로 금지 문장을 지운다.
- [x] 4.3 `npm test`, `npm run build`, `npm run test:browser`를 통과한다. 브라우저 테스트가 두발 기린의 경로를 스튜디오에서 그리고(취소 포함), 2번 지점을 멈추기·동작 2회·대기 0초로 바꾸고, 왕복·재생·지점 삭제 되돌리기·배치 미리보기를 거친다. 경로가 든 초안을 공개한 뒤 관람 화면에서 캐릭터가 자기 방에서 걷고, 다른 방을 보는 동안 멈추고, 돌아오면 다시 걷는 것도 확인한다. 휴대폰 기기 설정 두 종에서도 오류 없이 열린다. 지점 표식 끌기와 걷는 방향은 스튜디오 화면에서 직접 확인했다. 경로가 있는 캐릭터를 장면에서 끌어 방 밖으로 내보낼 때의 거부, 그리고 멈췄다 이어 걸을 때 자리가 이어지는지는 따로 확인하지 않았다(다시 움직이는 것까지 확인).
