# 클라우드 스튜디오에서 개정별 발행을 편집자 컴퓨터에 위임한다

## Context and Problem Statement

로컬 스튜디오는 운영자 맥의 파일과 Blender 실행 환경을 함께 사용한다. 사이트 운영 중에는 이 컴퓨터를 꺼도 다른 편집자가 저장·발행할 수 있어야 한다.

## Considered Options

- 로컬 스튜디오를 원격 네트워크로 연결한다.
- 클라우드가 Blender도 실행한다.
- 클라우드는 개정과 공개 상태를 관리하고 편집자의 도우미가 한 개정을 굽는다.

## Decision Outcome

세 번째 방식을 사용한다. Pages가 사이트와 API를 같은 출처로 제공하고 D1의 조건부 트랜잭션이 초안과 발행 상태를 관리한다. 스튜디오가 이 컴퓨터의 도우미를 확인한 뒤 한 개정의 원본을 읽고 결과를 제출할 수 있는 두 시간짜리 작업 권한을 전달한다. 검토를 선택한 경우 공개 승인은 스튜디오 세션에서만 가능하다. [관련 변경](../../openspec/changes/cloud-studio-helper/design.md)

### Consequences

- 도우미가 중단되어도 공개본은 계속 제공된다. 편집자가 저장하면 이전 작업을 취소한다.
- Apple Silicon 맥에서는 macOS 샌드박스, x64 Windows에서는 AppContainer가 Blender의 파일·네트워크 접근을 제한한다. 비공개 원본을 받을 수 있는 편집자에게만 로그인 키를 공유한다.
- 현재 장면 크기에서는 분할한 GLB와 공개 포인터를 D1에서 한 번에 커밋할 수 있다. 도우미 결과는 16 MiB까지 받는다.
