# 편집 버전이 참조하는 원본과 배치를 함께 보존한다

## Context and Problem Statement

이전 개정을 다시 열 때 Blender 모델의 방과 가구 식별자가 웹 배치와 일치해야 한다. 클라우드에서는 공개 개정과 현재 초안에서 벗어난 모델을 정리하므로 과거 배치만으로는 장면을 재구성할 수 없다.

## Considered Options

- 웹 배치만 보관하고 현재 모델에 적용한다.
- 각 시점에 전체 제작 파일을 새로 복사한다.
- 배치와 해당 모델의 식별자를 보관하고 참조 중인 원본을 공유한다.

## Decision Outcome

세 번째 방식을 사용한다. 이전 버전을 조회하는 동안에도 같은 모델 카탈로그와 편집용 장면을 열 수 있다. 복원은 새로운 초안 개정을 만들며 공개 개정의 교체는 기존 발행 흐름이 담당한다. [스튜디오 버전 기록 설계](../../openspec/changes/add-studio-version-history/design.md)

### Consequences

- 같은 모델로 편집한 여러 버전은 제작 원본과 편집용 장면을 공유한다.
- 자산을 정리할 때 보관된 버전의 참조까지 확인해야 한다. 개정 변경과 직전 상태의 보관은 함께 커밋한다.
