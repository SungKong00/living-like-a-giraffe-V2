# 전체 원본과 공개 장면을 개정별로 분리한다

## Context and Problem Statement

가구를 자유롭게 편집하는 Blender 원본과 휴대폰에서 가볍게 보이는 장면은 다른 구조를 요구한다. 행사 연결은 재발행 후에도 같은 가구를 가리켜야 한다.

## Considered Options

- 웹 공개 모델을 그대로 편집하고 Blender로 역변환한다.
- 전체 제작 원본을 보존하고, 저장된 개정에서 편집·공개 파생본을 만든다.

## Decision Outcome

두 번째 방식을 채택한다. 파일 작업자는 Blender 좌표·재질을 변환하고 서버는 ID 기반 배치 검증, 인계 시점 비교, 공개 포인터 교체를 맡는다. 브라우저의 되돌리기 이력은 편집 세션에 한정한다. [월드 인계 설계](../../openspec/changes/preserve-world-layout/design.md)

### Consequences

- 제작자는 전체 파일 하나에서 이어서 작업할 수 있고 방문자에게는 베이크와 검증이 끝난 개정이 제공된다.
- 서버는 Blender 작업 환경과 인계 기준을 보관해야 한다. 현재 저장 방식은 한 대의 macOS 작업 서버를 전제로 한다.
