## Blender 도구

장면을 조사하거나 수정할 때 [프로젝트 Blender 스킬](../../.agents/skills/riragi-blender/SKILL.md)을 사용한다. [Codex 설정](../../.codex/config.toml)은 Blender Lab 공식 MCP 소스를 고정 커밋에서 실행한다. 장면에 연결하려면 Blender 5.1 이상에서 공식 MCP 애드온을 설치하고 브리지를 시작한다. [Blender Lab 설치 안내](https://www.blender.org/lab/mcp-server/)

관람과 편집 화면은 v06 원본의 바닥 오브젝트 `Backdrop`에서 렌더한 조명 이미지를 공유한다. 바닥 조명을 갱신할 때는 초기 원본을 준비한 뒤 프로젝트 루트에서 `.venv/bin/python scripts/render-studio-floor.py`를 실행한다. 방 밑의 부드러운 그림자는 웹에서 현재 방 크기와 위치에 맞춰 근사한다.

## 전체 파일 인계

PC 스튜디오의 ‘전체 Blender 파일 인계’에서 저장한 초안 또는 현재 공개본을 내려받는다. 지정 장면은 장면 사용자 속성 `riragiWorld`가 참인 장면 한 개다. 서버 작업자는 Blender 4.2.17 Python 모듈로 원본을 다시 연다. 첫 인계 예시는 사우나 방의 ‘서쪽 나무 벤치’다. 부모 아래 좌판 두 단이 있고 바닥과 벽은 방에 남는다.

- 방 기준점에 `roomId`를 두고, 가구의 부모를 해당 방 기준점으로 지정한다. 가구 루트에 `itemId`, 모델 종류 `kind`, 표시 이름 `label`을 둔다. 기존 대상은 ID와 원점·축을 유지한다. Blender에서 새 가구를 복제하면 새 고유 ID를 준다. ID에는 소문자 영문·숫자·하이픈을 쓴다.
- 색과 표면 옵션은 Principled BSDF 재질에서 처리한다. 제작용 색·거칠기 입력을 상수로 사용하는 가구가 대상이다. 웹에서 설정한 옵션 속성과 인계 식별자 `handoff`를 보존한다. 웹의 클릭 영역과 행사 본문은 사이트가 관리한다.
- Blender의 외부 데이터 메뉴에서 텍스처·라이브러리를 패킹하고 저장한 전체 파일을 올린다. 충돌이 있으면 웹 또는 제작본 값을 선택하고 미리보기로 확인한다. 삭제된 가구에 붙은 클릭 영역은 다시 연결한다. ‘검토 결과를 초안에 적용’ 후 발행한다.
- 공개용 사본은 방의 고정 표면과 가구를 나눠 Cycles에서 빛과 색을 굽는다. 불투명 표면의 빛은 부동소수점으로 계산한 뒤 제작 장면의 뷰 변환·룩·노출을 적용해 웹용 sRGB 이미지로 저장한다. 기본 표면은 이 색을 그대로 표시하고, 무광·유광 옵션은 실시간 하이라이트를 더한다. 유리와 투과 재질이 있는 메시는 실시간 재질을 유지한다. 제작자는 내려받은 전체 파일에서 원래 구조·재질로 작업한다.

가구 종류별 허용 색상은 가구 루트의 문자열 속성 `webColors`에 쉼표로 구분해 적는다. 예를 들어 `#226655,#884422`면 두 색과 원본 색을 사용할 수 있다. 기본값 `*`는 모든 색을 허용한다. `webFinishes`에는 허용할 `matte,gloss`를 적는다. 같은 종류의 가구는 같은 옵션 정의를 사용한다.

## 스튜디오에서 조명 확인과 발행

1. 가구를 움직이며 클릭 영역을 확인할 때는 **배치 미리보기**를 연다. 이 화면은 실시간 조명을 사용한다.
2. 최종 색과 그림자를 보려면 **구운 결과 준비**를 누른다. 스튜디오가 초안을 저장하고 서버가 해당 개정의 관람 모델을 만든다. 다른 작업을 하거나 창을 닫았다가 돌아와도 된다.
3. **구운 결과 열기**에서 방과 가구를 확인한 뒤 **이 결과 공개**를 누른다. 창만 닫으면 결과는 비공개로 남는다. 검토한 뒤 초안을 다시 저장하면 최신 초안에서 결과를 준비한다.
4. 검토를 생략하려면 **공개 관리 → 바로 발행**을 선택한다. 서버가 처리를 마치면 요청한 개정이 공개된다. 두 방식 모두 **직전 공개본 복원**으로 이전 모델과 행사 연결을 함께 복원할 수 있다.
